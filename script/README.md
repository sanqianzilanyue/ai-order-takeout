# 脚本本体：点外卖的手

这是教程《[让 AI 替你点外卖](../README.md)》里那只手的**整支脚本**。
脱掉的只有三样：我家的坐标、她的地址簿关键词、支付口令的位置——全挪到了脚本外面。
其余一字没动，包括每一个坑原地留下的注释和日期。

它不是开箱即用的产品。它是在**她的**账号、**她家**那台机、那几家店上摔了七十四跤才学会走路的形状；
换一个人换一座城，前十趟大概率还要摔。摔之前把教程读完，摔的时候至少知道自己摔在第几个坑上。

| 文件 | 干什么 |
|---|---|
| `order.js` | 点外卖的手：搜店 → 进店 → 挑菜 → 加购 → 看底栏凑起送 → 结算页读金额 → 付款 → 回来报账，全程吐**一行 JSON** |
| `hand.js` | 慢手：一步一条命令，我看清楚了再走下一步。排障、演习用它 |
| `package.json` | 只有 `playwright-core`（不下载浏览器） |

## 一、先备三样东西

**1. 一间登录态长住的 Chrome**（别接管你日常那个，另起一间，开着 CDP 端口，藏到屏幕外）：

```bash
# macOS 示例；Linux 把 open -na 换成 google-chrome 即可
open -na "Google Chrome" --args \
  --remote-debugging-port=9222 \
  --user-data-dir="$HOME/.shop-chrome" \
  --window-position=2000,2000 --window-size=1280,900
```

第一次把窗口挪回屏幕里，打开 `https://h5.ele.me`，用淘宝扫码登录一回；登录态从此住在这个档案里。
**必须有头**（headless 直接甩验证码），**UA 一个字别改**（教程坑十五）。

**2. 依赖**

```bash
cd script && npm i
```

**3. 坐标、地址关键词、支付口令——都放在脚本外面**

`~/.takeout/places.json`：

```json
{
  "家":   { "latitude": 39.90, "longitude": 116.40 },
  "公司": { "latitude": 40.00, "longitude": 116.30 },
  "认":   { "家": "你小区的名字", "公司": "你园区的名字" }
}
```

- 坐标喂给 Chrome 当定位（教程第二天那一节：**没定位的会话去点外卖，风控当然甩九宫格**）。也可以用环境变量 `TAKEOUT_LAT` / `TAKEOUT_LNG`，或参数 `lat` / `lng`。
- `认` 是切收货地址时在地址簿里认那一条用的关键词（`addr:"公司"` 就去找含「你园区的名字」的那条）。
- 支付口令：环境变量 `PAY_PWD`，或 `~/.takeout_pay`（`chmod 600`）。**不想让它碰钱就都别填**——它会走到密码框前停下，死讯里写明「要支付密码」，你在手机上付。
- 可选：`SHOP_CHROME_SHOW` 填一条 shell 命令，撞验证时脚本会执行它把 Chrome 窗口挪回屏幕里给人划（不填就只报讯）。

## 二、用法

```bash
node order.js '{"kw":"冰美式","店含":"瑞幸","max":30}'                 # 搜商品名、认招牌、实付上限
node order.js '{"kw":"米线","max":50,"dry":true}'                        # 试运行：走到结算页读金额就停，一分不花
node order.js '{"kw":"蛋糕","dish":"梦龙雪媚娘","规格":["大杯"],"max":40}' # 点名菜与规格
node order.js '{"kw":"冰美式","店含":"瑞幸","addr":"公司","max":30}'      # 送到地址簿里的「公司」
node order.js '{"续付":true}'                                            # 订单已生成只差付款：只付那笔，不再生一单
node order.js '{"kw":"粥","只清车":true}'                                 # 进店把车倒干净就收工（演习留的脏车）
```

| 参数 | 意思 |
|---|---|
| `kw` | 搜什么。**直接搜商品名**，别搜店名进店翻菜单（坑二十一）。≥4 字当菜名；2~3 字先到菜单里对一遍，对不上才当品类词挑月售高的 |
| `dish` | 点名的那道菜。口语里的杯型/冰热会自动剥成规格（「冰美式」→ 标准美式 + 冰） |
| `店含` | 店名必须含这几个字；一家都对不上就收手报店单，**不兜底进第一家** |
| `shop` | 用另一个词搜店（默认用 `kw`） |
| `规格` | 数组，如 `["大杯"]`；没点名的规格一律不动默认档 |
| `qty` | 几份，只跟着点名的那样走 |
| `max` | 实付上限，超了先撤货再死 |
| `addr` | `家` / `公司` / 任意地址簿关键词；切了地址 URL 里就不带坐标（坑十） |
| `认` | 临时覆盖地址关键词表，同 places.json 里的 `认` |
| `dry` / `探` | 走到结算页读金额就停；`探` 还把足迹和 DOM 结构带回来 |
| `续付` | 只付 15 分钟内待付的那单 |
| `清车` / `只清车` | 进店先倒车 / 倒完就收工。整车清空只留给人亲口喊的这条命令 |
| `跳加购` | 车里本来就有，这趟只管结账 |
| `日上限` | 一天最多几单（默认 1）。同店一天只进一次——这两道闸在动页面之前就查，撞了连浏览器都不惊动 |
| `第几` | 从搜索结果第几家开始看（一趟最多看三家） |
| `菜单` | 只抄第一家能进的店的菜单，不买 |
| `lat` / `lng` / `geohash` / `cdp` | 临时覆盖坐标 / CDP 地址 |

## 三、它回来会说什么

成功：`{"ok":true,"店":"…","菜":[…],"实付":18,"单号":"…","eta":"…","shot":"截图路径"}`

死了：`{"ok":false,"哪步":"搜店|进店|加购|结算|付款|闸|登录|连浏览器…","为什么":"…","足迹":[…]}`——
**足迹永远随死讯带上**（坑七十）。它说「手坏了」的时候，先看足迹，别先看代码。

旁边会长出两样：`外卖账.json`（一天一单、同店一天一进的账本）、`截图/`（订单详情页那张）。
怎么把这行 JSON 变成你自己的口气告诉她——教程第十四节，留给你自己的后端。

## 四、慢手 `hand.js`

```
node hand.js 页                 列出那间 Chrome 里的页
node hand.js 去 <url>           导航
node hand.js 读 [字数]          读当前页正文
node hand.js 找 "文字" [n]      找含该文字的叶子元素，报坐标
node hand.js 点字 "文字"        找到第一个就点（真鼠标）
node hand.js 滑 <dy> [次数]     慢慢滚
node hand.js 窄 / 宽            窗口掐成手机宽 / 还原
node hand.js 眼                 只查人机验证 / 登录态
```

## 五、风控礼仪（别跳过这一节）

慢。一天一单。同店一天一进。定位要喂。UA 别改。演习不留脏车。先 `dry` 再真跑。
撞了九宫格就停手交给人，等人划完、凉一会儿再开枪——**验证不是让你绕的，是让你停的**。
她说过的那句被我原样焊进了脚本：**「下次慢一点就行，像真人一样呗。」**
